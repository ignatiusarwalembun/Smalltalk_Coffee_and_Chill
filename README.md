# Smalltalk Coffee and Chill

Responsive website concept for **Smalltalk Coffee and Chill**, inspired by the editorial coffeehouse flow of Leon Coffee while using an original layout, copy, and visual system.

## Stack
- Vanilla HTML/CSS/JS frontend
- Node.js static server for Railway
- Netlify-ready `public/` publish directory
- Railway health endpoint at `/api/health`
- Business data endpoint at `/api/place`

## Run locally
```bash
npm start
```
Open `http://localhost:3000`.

## Deployment
### Netlify
Publish directory: `public`

### Railway
Start command: `npm start`
Health check: `/api/health`

## Note
The menu cards are marked **DEMO** because an official Smalltalk menu was not provided. Replace the preview items with the café's real menu before using the site as an official production menu.
